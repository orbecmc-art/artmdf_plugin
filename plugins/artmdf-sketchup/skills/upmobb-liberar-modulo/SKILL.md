# Liberar módulo UpMobb para os projetistas

Todo módulo colocado na biblioteca nasce com status **Desenvolvedor** (card vermelho). Para os projetistas o enxergarem, ele precisa ter ambientes e descrição abreviada preenchidos e ser movido para **Básico** (card branco, etiqueta verde).

## Quando usar (automático)
Sempre que o usuário salvar/enviar um módulo novo para a biblioteca dele (MDF ARTE DESIGN), ou avisar que salvou um, não espere ser pedido: siga este fluxo até o fim, usando o produto que acabou de ser feito. Não pergunte "quer que eu libere?"; apenas faça. Pergunte somente o que não der para deduzir (veja abaixo). Se o usuário ainda não tiver salvo o módulo, pergunte nome e categoria, ou ofereça conferir a lista de módulos com status Desenvolvedor.

## Como descobrir os dados do produto
- **Nome do módulo**: o nome com que foi salvo (ex.: "Balcão Gavetas Cava Travessa"). Se não souber, ele é o card vermelho "Desenvolvedor" no fim da categoria.
- **Categoria**: a pasta onde foi salvo (ex.: INFERIOR CAVA, INFERIOR, SUPERIOR, ALTOS, PORTAS, PAINEIS...). Corresponde ao item da lista azul no painel.
- **Descrição abreviada**: texto curto em maiúsculas derivado do nome e da categoria, no padrão da biblioteca (ex.: "Balcão Gavetas Cava Travessa" na categoria INFERIOR CAVA → "INF CAVA TRAVESSA"; outros cards usam "INF 3 GV", "INF 2 PORTAS", "INF 1 GAVETAO"). Abrevie INFERIOR→INF, SUPERIOR→SUP, GAVETA→GV.
- **Ambientes**: deduza pelo tipo de produto. Referência gravada: módulo inferior de gavetas → cozinhas, dormitórios, sala de TV, escritórios, banheiros, lavanderia (todos os ambientes onde o produto serve; não marcar USINAGEM AVULSA, CENAS, PEÇAS AVULSAS, TAMPONAMENTOS, a menos que faça sentido). Se o produto for específico (ex.: só banheiro, só cama) e você não tiver certeza, pergunte uma vez ao usuário, em uma pergunta só com as opções.

## Passos (navegador: Claude in Chrome ou navegador embutido, não cliques de desktop)
1. Abra https://upmobb.com.br/mdfart/ (favorito "UpMobb") e clique em **Área Restrita**.
2. Login: peça ao usuário para fazer o login (não digite credenciais por ele) e aguarde ele confirmar. Se a sessão já estiver logada, siga.
3. No Painel de Ações, menu lateral: **Modulos**.
4. Aba **Base** > botão **MDF ARTE DESIGN**.
5. Na lista azul, clique na categoria. Role a lista de cards até o módulo (o novo fica no fim, etiqueta vermelha "Desenvolvedor").
6. Clique no card para abrir o modal.
7. Em **Ambientes**, marque as caixas deduzidas (role a lista se necessário; confira o check verde).
8. Clique em **Descrição abreviada**. Pode surgir uma lista de sugestões do navegador (TORRE QUENTE, CAMA COM GAVETA...); ignore, apague texto indesejado e digite a descrição.
9. Clique em **Salvar** (fica cinza depois de salvo). Feche o modal clicando fora.
10. No card, clique na etiqueta **Desenvolvedor** para virar **Basico**. O card fica branco com etiqueta verde (aparece "Status alterado" no topo).

## Verificação e resposta final
- Card branco com etiqueta verde "Basico".
- Reabrir o módulo e confirmar ambientes e descrição salvos.
- Diga ao usuário em uma ou duas frases: nome do módulo, categoria, ambientes marcados e descrição usada, para ele conferir.

## Regras
- Nunca digite credenciais; o login é do usuário.
- Só mude para Básico depois de salvar ambientes e descrição.
- Se o módulo não aparecer, atualize a página e confira se o nome e a categoria batem; não libere outro módulo no lugar.
