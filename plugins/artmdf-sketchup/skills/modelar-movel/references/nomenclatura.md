# Nomenclatura de peças e módulos (pt-BR)

Os nomes que o UpMobb dá às peças prevalecem no modelo. Este glossário serve para entender o que o usuário fala e para nomear coisas novas que você criar.


| Termo | Definição / uso na modelagem |
|---|---|
| Caixa / corpo | Estrutura do módulo (laterais + base + tampo + fundo) |
| Lateral | Painel vertical da caixa (esq./dir.) |
| Divisória | Painel vertical interno fixo |
| Base | Painel horizontal inferior da caixa |
| Tampo | Painel horizontal superior da caixa (≠ tampo de pedra/bancada) |
| Travessa | Régua horizontal (frente/trás) substituindo tampo; ou reforço |
| Fundo | Painel traseiro fino (3/6 mm) |
| Prateleira | Painel horizontal interno (fixa ou móvel) |
| Porta | Fechamento articulado (giro), basculante ou de correr |
| Frente de gaveta | Face externa aparente da gaveta |
| Contra-frente | Frente interna da caixa de gaveta (onde a frente externa é parafusada); em alguns usos regionais, a traseira da gaveta |
| Traseira de gaveta | Painel de trás da caixa de gaveta |
| Lateral de gaveta |  |
| Fundo de gaveta |  |
| Rodapé | Faixa inferior recuada (MDF, alumínio ou alvenaria) |
| Testeira | Faixa horizontal frontal de acabamento (sobre portas, entre módulo e teto/sanca, ou saia da pedra) |
| Tamponamento / tampo lateral | Painel de acabamento aplicado sobre lateral/topo aparente, geralmente 18–25 mm |
| Engrosso | Borda engrossada (2 chapas ou tira colada) em tampos/prateleiras |
| Desempenador | Perfil metálico embutido contra empeno de portas altas |
| Cabideiro | Tubo/perfil para cabides |
| Maleiro | Compartimento superior do guarda-roupa para malas |
| Sapateira | Prateleiras/gavetas para calçados |
| Nicho | Vão aberto sem porta (ou nicho de eletrodoméstico) |
| Torre | Módulo alto (piso → topo dos aéreos) |
| Torre quente | Torre com nichos para forno/micro-ondas |
| Paneleiro | Torre/armário alto de despensa ou panelas |
| Balcão | Módulo inferior sob bancada |
| Aéreo | Módulo superior fixado na parede |
| Gaveteiro | Módulo ou bloco de gavetas |
| Rodabase / frontão | Faixa de pedra na parede atrás da bancada (10–15 cm) |
| Calço / base da dobradiça | Peça fixada na lateral (linha 37 mm) |
| Caneco | Copo da dobradiça (Ø 35) na porta |
| Corrediça telescópica / oculta | Trilhos de gaveta |
| Fita de borda | Acabamento das bordas |
| Veio | Direção do padrão amadeirado |
| Furação modular / sistema 32 | Linhas de furos Ø 5 a 37 mm, passo 32 |

Fontes de glossário: [Duratex — dicionário da marcenaria](https://www.duratexmadeira.com.br/blog/dicionario-da-marcenaria-conheca-conceitos-do-dia-a-dia-de-um-marceneiro) · [Cursa — detalhamento técnico de marcenaria](https://cursa.app/pt/exercicios/designer-de-interiores/detalhamento-tecnico-de-marcenaria-planejada-residencial). Os termos testeira, tamponamento, engrosso, contra-frente são de uso corrente [P]; "contra-frente" varia por região — confirmar com a marcenaria.

## Termos usados na Art MDF (ouvidos nas sessões)

| Termo | Significado |
|---|---|
| Pega | Puxador; "altura da pega" = comprimento do puxador cava/perfil |
| Cava | Puxador usinado na chapa (rebaixo) ou perfil embutido (ex.: RM416) |
| Régua da cava | Peça horizontal entre frentes que forma a cava |
| Ponteira (aberta/fechada) | Acabamento das pontas do perfil de puxador |
| Tamponamento | Laterais e tampo externos que cobrem a caixa |
| Niveladores / sapatas | Pés reguláveis |
| Presagem | Fresagem (erro comum de transcrição de voz) |
| OpenMob / Up Mob | UpMobb (transcrição de voz) |
